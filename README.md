# 🚀 AI-Powered Real-Time Crypto Intelligence Platform

## 📌 Overview

A full-stack fintech analytics platform that delivers:

- Real-time cryptocurrency analytics
- Machine learning price prediction
- AI trading insights
- Interactive fintech dashboards
- Live API-based crypto streaming

Built using React, Flask, MySQL, and Machine Learning.

---

# ⚡ Features

## 📊 Analytics Dashboard
- Real-time crypto visualization
- Interactive charts
- KPI tracking
- Volatility analytics

## 🤖 Machine Learning
- Linear regression price forecasting
- AI Buy/Sell/Hold signals
- RSI-based analytics

## 🔄 Real-Time Streaming
- CoinGecko API integration
- Live crypto data ingestion
- Automated ETL pipeline

## 💼 Portfolio Module
- Portfolio overview
- Asset analytics
- Market insights
